# 追忆合击工具箱

Windows 双角色工具箱与 BOSS 刷新计时器。一个窗口切换账号1、账号2和 BOSS 计时；两号的角色绑定、加密登录配置、命令、统计和日志分别保存。

**让AI安装或排查时，请先让它完整阅读 [AI安装与运行说明.md](AI安装与运行说明.md) 和 [AGENTS.md](AGENTS.md)。** 详细用户要求、恢复限制、现场验收标准和日志表均在交接说明中。

## 另一台电脑快速开始

1. 在本仓库点 **Code → Download ZIP**，解压到普通可写文件夹。不要在 ZIP 内直接打开。
2. 安装 **Python 3.13 64位**（本项目使用的测试版本），保留 Python Launcher 和 Tcl/Tk 组件。下载地址：[Python 官方 Windows 下载页](https://www.python.org/downloads/windows/)。
3. 双击 **`首次安装.bat`**，创建本项目专用 `.venv` 并安装依赖。每台电脑首次使用做一次。
4. 双击 **`启动工具箱.bat`**，以后只需双击这个文件。Windows 会请求一次管理员权限，供只读访问游戏进程使用；请自己确认系统提示。
5. 第一次启动选择**游戏客户端根目录**，里面应有 `map` 文件夹。也可在本机 `config/toolbox.local.json` 修改 `game_directory`，或设置环境变量 `MIR_GAME_DIR`。改变目录后需重新打开工具箱。
6. 手动登录游戏，在两个角色页各自的“角色设置”里选择对应角色，再连接。一个游戏进程不能同时绑给两个角色页。先确认角色名再启动任务。

`清包工具.pyw`、`双角色工具箱.pyw` 也是合并窗口入口；批处理入口会固定使用安装好的虚拟环境，避免 `.pyw` 文件关联到错误的 Python。

## 功能与使用

- **日常操作**：普通房间挂机、满包转英雄、双包回城按白名单出售、接续当前地图。
- **孤岛挑战**：进入或接续当前挑战；优先处理掉落。完整无人干预流程仍待持续现场验证。
- **状态与收益 / 经验与击杀**：两号分别记录。击杀参考统计和公告计时均不等于服务器权威计数。
- 重设收益时，在本号“状态与收益”页顶部点击 **重设收益起点**。统计按钮固定在顶部，明细区可滚动，不会因文字过长被挤掉；重设只改收益基线，不停止挂机、不清零恢复计数或经验统计。
- **BOSS计时**：监听全服掉落公告。多开时选择其中一个角色监听即可，不需要两个号各监听一份。
- 当前行为：同地图同名怪在3秒内的掉落公告合并计时；祖玛精英默认2位、石墓七层精英白野猪4位、牛魔大厅牛魔王1位。超量公告保留待核对，不自动扩增计时位。真正不同怪在3秒内死亡也可能合并，这是公告估算的限制。
- 预计刷新后绿色保持2分钟，之后灰色超时；预计刷新5分钟后从列表移除。
- 关闭合并窗口会请求安全停止工具任务；游戏客户端不会被关闭。切换页面不会停止任务。
- 恢复累计在本号目录内按角色分别保存；换角色不会继承旧角色额度，也不会清掉旧角色累计。切回旧角色仍保留此前次数。旧计数文件迁移时先备份，不能通过删文件重置。

## 哪些内容不随代码迁移

游戏客户端、地图、账号密码、DPAPI 加密凭据、角色绑定、运行日志、个人统计均不在源码发布包中。另一台电脑必须重新选择客户端目录和角色；需要自动登录时在对应角色页重新配置加密登录信息。DPAPI 文件绑定原 Windows 用户/电脑，不能靠复制文件跨电脑使用。

默认运行数据位于 `outputs/`，账号2位于 `instances/2/`；BOSS计时数据位于 `outputs/BOSS计时器/`。备份或更新时保留这些目录。仓库已有的 `log/` 是用户主动上传的诊断样本，不是新电脑的运行数据，不会自动当作实时状态加载。

需要排查时双击 **`导出诊断日志.bat`**，在 `outputs/诊断包/` 得到带电脑名和时间的 ZIP。两台电脑分别导出，不混用实时文件。诊断包排除凭据、DPAPI、绑定和截图，但日志可能含角色名、坐标和余额，上传前检查。首次未运行对应功能时，相应日志可能还不存在。

## 更新

停止工具任务并退出工具箱后下载新版 ZIP。可另解压一个目录，完成首次安装、重新绑定；或将新版源码覆盖到原目录，**保留 `.venv/`、`config/`、`outputs/`、`instances/`、`private/`**。如 `requirements.txt` 更新，再运行首次安装脚本。不要在任务中途覆盖并重启。
